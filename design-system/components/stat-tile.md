# StatTile (`.yu-stat`)

A headline figure in the `mono` data face — the one deliberate nod to accounting's numbers discipline.

```html
<div class="yu-stat">
  <span class="yu-stat__value stat">212</span>
  <span class="yu-stat__label label">Active Members</span>
</div>
```

Use it for figures a reader should register at a glance: membership counts, case-competition placements, sponsorship dollars, event attendance. The value sets in `.stat` (34px mono, tabular numerals); the label sets in `.label` (uppercase, letter-spaced) in `ink-muted`.

Keep each tile to one figure. A row of StatTiles reads as a scoreboard — don't mix in prose or icons that compete with the number.
