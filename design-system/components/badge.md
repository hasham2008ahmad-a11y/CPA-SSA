# Badge (`.yu-badge`)

Small tags for event types and affiliation, on event listings, the chapter calendar and social graphics.

```html
<span class="yu-badge">Case Competition</span>
<span class="yu-badge">Info Session</span>
<span class="yu-badge yu-badge--national">ACE Canada National Event</span>
```

- **default** — `brand-secondary-tint` fill, `brand-primary` text. Use for anything chapter-run: event categories, chapter roles, general status.
- **`yu-badge--national`** — `national-accent` fill, `national-accent-ink` text. Use only to flag that a specific event or post is an ACE Canada national event, not a chapter one — it should stand out as the exception, not blend in as another category colour.
